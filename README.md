# Colonos de Catán
Versión simplificada y funcional del juego, que permite a varios jugadores
conectarse en línea para crear o unirse a partidas y jugar por turnos.
Este proyecto es una continuación mejorada de la base original:
[colonos-de-catan](https://github.com/scrum-prueba-team2/colonos-de-catan).  
Documentacion: https://drive.google.com/drive/folders/1wTsdb3vVVHQuPS7S0cji2dnk0LFrYyeU?usp=sharing

## Metodología de trabajo
El proyecto busca usar metodología XP **Extreme Programming**, trabajando
en pareja para entregar cortas liberaciones que mejorarán la experiencia de juego.



## Release
**V1.1 - Beta**
Esta versión implementa el título que hacía falta de camino más largo y también mejora la forma de intercambio actual,
donde no se podía intercambiar de forma mixta como sí ocurre en el juego original. También puedes elegir el color con el 
que quieres jugar antes de entrar a una partida. (Para más detalles revisar la documentacion)

**V1.2 - Beta**
Esta versión cambia el diseño general de la partida, por uno más minimalista y llamativo a la vez, nuevo chat en la sala de espera,
mejor manejo de errores y una experiencia de juego mucho más agradable. (Para más detalles revisar la documentacion)

**V1.3 - Beta**
Esta versión integra cronómetros que se encargan de realizar automáticamente las acciones por parte de los jugadores por si 
hay ausencia de uno de ellos, además de permitir indicar cuantos puntos se requieren para ganar o algunos tiempos mismamente
de los establecidos por defecto (Para más detalles revisar la documentacion)
